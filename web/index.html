          Bundled Skills & MCP Tools
          
Six agent skills backed by five read-only MCP tools

          

            Every Kapibara tool sets readOnlyHint: true and
            destructiveHint: false. Kapibara never executes shell commands or mutates
            files on your machine.
          

        


        

          

            /kapibara:preflight-check
            
Preflight Check

            

              Evaluates shell commands, file deletions, git history rewrites, and deploys before
              execution. Returns allow, warn,
              require_approval, or block.
            

            

              kapibara_preflight
              Binding gate
            

          


          

            /kapibara:action-risk
            
Action Risk

            

              Scores any proposed action from 0 to 100 across 6 deterministic factors: destructive
              impact, reversibility, sensitive data, external side effects, production impact, and
              uncertainty.
            

            

              kapibara_action_risk
              0–100 score
            

          


          

            /kapibara:second-opinion
            
Second Opinion

            

              Challenges risky migrations, force-pushes, or production changes with a structured
              review: AGREE, AGREE WITH CHANGES, or
              DO NOT PROCEED.
            

            

              preflight + action_risk
              Plan critique
            

          


          

            /kapibara:consistency-check
            
Consistency Check

            

              Compares two text sources (invoices vs emails, configs vs docs, lockfiles vs specs) to
              detect conflicting currency amounts, dates, versions, and contradictory statements.
            

            

              kapibara_compare
              Cross-source diff
            

          


          

            /kapibara:sensitive-data-check
            
Sensitive Data Check

            

              Scans text and file paths for API keys, tokens, PEM private keys, PII, and
              prompt-injection patterns, returning masked previews (sk-proj-****) and
              redactions.
            

            

              kapibara_scan_sensitive
              Auto-redaction
            

          


          

            /kapibara:setup
            
Agent & Rules Setup

            

              Connects the @kapibara/mcp server to Claude Code, Codex, Cursor,
              OpenCode, or Claude Desktop and enforces plain-English rules in
              .kapibara/rules.md.
            

            

              kapibara_rules_check
              Plain-English rules

            Kapibara
          
          

            Kapibara is a lightweight verification and risk-check layer for AI agents. Before an
            agent deletes files, force-pushes, deploys to production, or sends sensitive payloads
            externally, Kapibara evaluates project rules in
            .kapibara/rules.md, scores risk across six deterministic factors, and
            returns structured decisions over MCP stdio.
